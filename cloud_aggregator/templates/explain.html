How good is each method? (measured on 100 correctly-classified test windows)

The interpretability–latency trade-off. A gradient needs one backward pass; Integrated Gradients ~32; occlusion ~63 forward passes. On a microcontroller only the cheapest is realistic, so the design here is: decide on the edge with the INT8 model, explain in the cloud on demand with the FP32 model — and only the one window under investigation needs to be pulled from the device (explain-on-alert), never the whole stream.
