Edge Compression & Benchmarks

A model that wins on a GPU is useless if it doesn't fit the device. Two independent knobs shrink it: INT8 quantization (fewer bits per weight) and structured pruning (fewer filters, fine-tuned federatedly). Every row below is the mean over seeds, and includes a control that gets the same extra training as the pruned models — so any “pruning improved accuracy” claim is tested, not assumed.

Measured latency (this machine, official model)

Read latency carefully. TFLite latency is the same for the full and pruned model: for a model this small the interpreter's per-call overhead dominates, not the arithmetic — so the compute saving from pruning (MACs column) only shows up on a slower core where arithmetic matters. Keras's ~10 ms is eager-mode overhead, not a fair comparison. These numbers rank variants on the host CPU; they are not Raspberry Pi numbers.
